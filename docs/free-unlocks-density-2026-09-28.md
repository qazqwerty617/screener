# Бесплатные разлоки и карта плотностей — 28 сентября 2026

## Найдено и исправлено

Пустая карта была связана с работой сервера, а не только с фильтрами. В PM2 сервер получал лимит 350 МБ от окружения оркестратора: `reload/restart --update-env` передавал служебные параметры вызывающего процесса. Это вызывало перезапуски примерно каждые 30 секунд, HTTP 502 и повторный прогрев стаканов. Восстановление теперь использует конфигурацию нужного приложения и очищенное от управляющих параметров PM2 окружение. Исправлен также обычный скрипт деплоя.

Список инструментов больше не ждёт завершения внешнего справочника RWA. Сразу работают существующие локальные исключения; после получения справочника список пересчитывается. Зависший ответ не блокирует все 11 бирж. Тест с никогда не завершающимися запросами подтверждает старт и добавление новых инструментов.

Длительное наблюдение выявило дополнительную причину перезапусков: нормальное потребление около 1,1 ГБ попадало под отдельный порог оркестратора 1150 МБ или статистический z-score. Жёсткий бюджет теперь берётся из ecosystem.config.js: 1800 МБ RSS, 1024 МБ V8 heap с запасом для native memory и буферов. Статистический всплеск сам по себе не перезапускает здоровый сервер. Проверки зависаний и жёсткого бюджета сохранены. Это согласование бюджета с измеренным потреблением; снижение всей памяти приложения данным изменением не заявляется.

Вечерняя проверка обнаружила, что одного исправления лимитов недостаточно: процесс продолжал завершаться с V8 heap out of memory. Sampling-профиль показал большой объём выделений в CCXT `setMarkets`, копировании валют и полных ответов бирж. Сборщик листингов теперь вызывает `fetchMarkets`, оставляет только идентификаторы, активность и официальные поля расписаний, отключает сохранение полных HTTP-ответов. Для Binance/Bybit/OKX/Gate не запрашиваются ненужные типы рынков; prerequisite справочника Hyperliquid сохранён. Торговые индексы `loadMarkets` больше не создаются. Перед выкладыванием отдельный живой проход по всем 11 биржам вернул те же наборы подходящих пар, что рабочий каталог: ни одной отсутствующей пары. Повторный профиль больше не показал выделений `setMarkets`. Это устраняет измеренный источник нагрузки, но не доказывает отсутствие других утечек.

Frontend карты: один fallback-запрос одновременно, таймаут 10 секунд, защита от старого HTTP-снимка после нового WS-снимка и от поздней HTTP-ошибки после восстановления WS. Пустой актуальный снимок удаляет исчезнувшие плотности. Статусы показывают ошибки, ожидание инструментов/стаканов и отсутствие результатов фильтра; tooltip содержит охват каждой биржи.

## Разлоки

- DropsTab: публичный запрос календаря, тот же endpoint, который использует страница [Vesting](https://dropstab.com/vesting). Обход страниц без фильтра только крупных событий. На проверке: 580 проектов прочитано, у 576 есть пригодные датированные события в поддерживаемом диапазоне. Это охват данного источника, не всех токенов мира.
- Tokenomist: только содержимое [публичной первой страницы](https://tokenomist.ai/), без обхода авторизации. Прочитано 25 строк, 15 содержали пригодное ближайшее событие. 642 в метаданных — размер каталога поставщика, не число отслеживаемых нами проектов.
- Официальные вычисляемые расписания XPL/ARB/APT сохранены; платный DefiLlama остаётся необязательным. Противоречивые суммы разных поставщиков не складываются и не подменяют официальное расписание.
- Cliff и linear — отдельные записи и фильтры. Linear обозначается как ближайшая порция по источнику; месячная порция не выдаётся за суточную эмиссию.
- Точность Tokenomist сохранена: месяц показывается месяцем, неделя — окном ±3 дня; поиск по периодам учитывает пересечение интервалов. [Методология точности поставщика](https://docs.unlocks.app/tokenomist/token-page/precision-and-assumption).
- Официальные RSS Sui и Arbitrum добавлены в существующую новостную систему. Sui использует канонический адрес `https://www.sui.io/blog/rss.xml`, поскольку старый адрес перенаправляет запрос. Распознанные публикации о разлоках из подключённых проверенных издателей отображаются отдельно и не превращаются автоматически в выдуманную дату/сумму.
- Загрузка календарей не задерживает обновление новостей. Период повторного чтения 30 минут, ошибки — backoff 5 минут, запросы объединяются. Размер ответа, число страниц и время обхода ограничены. При ошибке сохраняется предыдущий кэш: после часа он явно устаревший, после суток скрывается. Валидный пустой календарь отличается от ошибки источника.

## Проверки

Полный Node test suite: 814/814 тестов. Успешны `go test ./...`, `go vet ./...`, проверка синтаксиса изменённых JS и `git diff --check`. Добавлены проверки пагинации, повторов, нечисловых объёмов, поддельных ссылок, точности дат, лимита ответа, освобождения соединений после HTTP-ошибок, пустых ответов, недоступности одного/обоих источников, истечения кэша, конкурентных запросов и восстановления. Дополнительные тесты проверяют сохранение дат при компактном чтении листингов, повторное чтение после ошибки Hyperliquid и отображение конкретного часа разлока.

В браузере проверены реальная страница приложения с локальным тестовым входом, карта на публичных рабочих данных, сброс фильтров, вкладки событий, фильтр cliff, поиск XPL, сохранение официального расписания, неопределённые даты и пустые результаты. Зафиксированы 11/11 бирж, около 93% свежих стаканов и около 190 отображаемых плотностей до финального выкладывания; значения меняются с рынком. Утром production API возвращал 580/580 проектов DropsTab и 792 записи календаря вместе с прочими источниками. Вечером после обновления источника: 579/579 проектов проверено, у 575 есть события, 791 запись суммарно. Эти значения подтверждены также на публичной странице разлоков.

Деплой выполнен только для перечисленных файлов приложения через сравнение хешей с прочитанным состоянием сервера и резервные копии. Базы пользователей не изменялись. Проверка API не требовала доступа к пользовательским аккаунтам.

Контроль 28 сентября, 17:55 UTC, после финального рестарта в 17:52:43 UTC: HTTP 200, 150 плотностей, 10/11 бирж карты (MEXC временно throttled), 2957 свежих стаканов из 5207 во время прогрева. Каталоги листингов всех 11 бирж имели статус `ok`; Sui и Arbitrum RSS доступны. RSS Node около 778 МиБ, счётчик PM2 оставался 732 после запланированного обновления. Это короткий контроль, а не многосуточный soak test; сравнение с прежними 1,2 ГиБ нельзя считать установившимся процентом экономии памяти. Визуально проверен заполненный радар в локальном интерфейсе с рабочими публичными данными, календарь — на production; JavaScript-ошибок в этих вкладках не обнаружено.

## Объективные ограничения

Публичные интерфейсы поставщиков могут меняться и ограничивать доступ. Первая страница Tokenomist не даёт полного каталога; остальная пагинация требует входа. DropsTab содержит ближайшие порции по распределениям, а не полную историческую базу и не все будущие повторения на год. Выбор «Год» ограничивает доступные события этим горизонтом и не обещает все разлоки за год.

Глобальный сбор всех Twitter/X и Telegram-каналов не реализован и не заявляется. Существующий Telegram-приём ограничен подключёнными каналами; произвольный текст не считается подтверждённым календарём. В момент проверки новых подходящих публикаций могло не быть — это честное пустое состояние.

Сканер соблюдает ограничения API бирж: временные throttling и неполный охват стаканов видимы. Полный многосуточный прогон финальной конфигурации, отсутствие всех утечек во всём проекте и проверка каждой кнопки приложения не подтверждены. Go race detector в этот прогон не входит.
