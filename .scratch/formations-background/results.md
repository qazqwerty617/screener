# Формации: фоновая подготовка и настройки

Изменения подготовлены локально. Рабочий сервер не обновлялся; реальные Telegram-сообщения при проверке не отправлялись.

- Вкладка получает единый серверный снимок всех типов формаций. Серверный поиск не зависит от посетителей. Пустой результат больше не запускает сканирование монет в браузере.
- В фоне подготавливаются свечи текущей и следующей страницы, максимум три загрузки одновременно. Ограниченный локальный кэш сохраняет последний рабочий снимок и свечи для повторного открытия.
- Настройки типа, таймфрейма, количества графиков, касаний, бирж, ближайших уровней, режима ретестов и фильтров сохраняются; синхронизация аккаунта обращается к действительному состоянию вкладки.
- Пустые снимки удаляют исчезнувшие формации. Просроченные серверные результаты исключаются. Неудачная загрузка не стирает последнюю доступную выборку.
- Уведомления через WebSocket и резервный опрос используют общий обработчик: объём, биржи, касания, расстояние, направление, стадия и возраст ретеста, чёрный список, интервал на монету.
- Скрытая форма авторизации больше не блокирует уведомления. Telegram использует выбранный интервал; скрытый минимум 15 минут удалён. Дополнительные таймфреймы также передают сигналы серверному диспетчеру.
- Сохранение уведомлений ждёт подтверждения сервера, запросы упорядочены, неуспешные сохранения повторяются. Загрузка старых настроек не затирает ожидающее сохранение.
- Один результат геометрического анализа используется и для списка, и для генерации сигналов; повторный проход детекторов исключён.

Проверки: `cd node-server; node --test tests/*.test.js` — 567 тестов прошли, пропусков нет. Дополнительно проверены синтаксис и diff. Браузер: реальные HTML/CSS/JS на локальном сервере с синтетическими рыночными данными; открытие вкладки, свечи, фильтр монеты, смена таймфрейма, восстановление после перезагрузки, подтверждение сохранения уведомлений. Ошибок JavaScript не обнаружено.

Локальный микротест: 600 свечей, 200 итераций; повторный расчёт 0,832 мс, повторное использование 0,360 мс на итерацию (около 57% меньше времени). Это измерение вычислений, а не сетевой задержки бирж. Воспроизведение: `node .scratch/formations-background/benchmark.cjs`.

Ограничения: 5m/15m/1h используют существующий проход по всем уникальным активам с распределением нагрузки между биржами; 1m/4h/1d/3d/1w — до 300 монет за проход. Это не полное покрытие каждой монеты на каждой бирже. Охват отображается в интерфейсе. Полностью холодному серверу нужно время на первый проход; доступность и задержки внешних бирж требуют проверки после развёртывания. Звук/всплывающие уведомления требуют открытого сайта; Telegram работает на сервере.

`preview.cjs` — изолированный локальный стенд без исходящих сервисных вызовов. `test-results.txt` — полный результат тестов.
