# Official project announcement coverage

Implement website-attested official social account discovery beyond a small fixed
token list, with public Telegram and official website feeds, optional authenticated
X and Discord readers, transparent source health and a high-signal announcement UI.
Exclude promotional noise and keep social unlock mentions separate from dated,
quantified calendar events. Do not treat discovery candidates as connected sources.

Acceptance: verify provenance, source failures, persistent catch-up, shutdown,
edits, safe transport, bounded memory/requests, paginated UI and stale-response
protection; preserve existing news, listings and unlock calendars. Document provider
and coverage limitations. Implementation notes: `docs/official-social-coverage.md`.
