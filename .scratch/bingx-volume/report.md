# Проверка объёмов BingX

Дата: 20 сентября 2026. Источник: публичные REST и WebSocket BingX Futures.

## Охват

BTC, ETH, SOL, DOGE, ZIL, FIDA; интервалы 1m, 15m, 4h.
18 выборок по 119 закрытых свечей: 2 142 свечи.
Снимок данных: `capture.json`; воспроизводимая проверка:

```powershell
node .scratch/bingx-volume/diagnose.cjs --replay
```

## Подтверждённые дефекты и исправления

1. Основной график принудительно задавал минимум 1,5 px всем положительным
   объёмам. Разные небольшие значения рядом со всплеском становились одинаковыми.
   На сохранённой выборке DOGE 1m при высоте панели 100 px это затронуло 68 из
   119 столбиков. Минимум убран; Canvas рисует дробные высоты пропорционально
   объёму. Это общая поправка отрисовки для всех бирж. Очень маленькие объёмы
   могут быть слабо видны при большом всплеске; их значения не увеличиваются.
2. Живой BingX прислал три gzip-сообщения `Ping` за 18 секунд. Браузерный и
   серверный обработчики пытались разобрать их как JSON и не отвечали `Pong`.
   Добавлена обработка текстового heartbeat до JSON; удалён лишний серверный
   JSON-ping. Данные от заменённого соединения после распаковки игнорируются.
   Протокол подтверждён [официальной документацией BingX](https://github.com/BingX-API/api-ai-skills/blob/main/skills/swap-ws-market/api-reference.md).

Версия браузерного app.js обновлена до 2103 для обновления кеша.

Для всех выборок REST-парсер сохранил объём как baseVolume × close — текущую
оценку объёма в USDT в приложении. Это не точный оборот по ценам каждой сделки.
Сверены также сжатые WebSocket-сообщения всех шести пар через реальные
серверный и браузерный обработчики.

Похожие четырёхчасовые объёмы FIDA и ZIL присутствуют уже в ответах API.
Исправления не добавляют к этим данным искусственные различия. Проверка FIDA
из предыдущего прохода сама по себе не позволяла сделать вывод обо всём BingX.

## Проверки и ограничения

- Перед исправлением: 13 новых проверок воспроизвели дефекты (масштабирование
  и heartbeat двух обработчиков на шести парах).
- После исправления: 35 целевых проверок проходят.
- Повтор сохранённой выборки: все 2 142 свечи сохраняют пропорции объёмов.
- Общий набор: 676 тестов, 676 успешных.
- `git diff --check`: без замечаний.

Изменения выполнены в рабочей копии. Развёртывание на удалённом сервере и
длительный мониторинг соединений не выполнялись. Выборка не охватывает каждый
контракт BingX; одинаковый вид столбиков в каждом возможном случае не доказан
как следствие найденных ошибок.
